# Разработка с AI-агентом

Проект сделан в паре: разработчик + [Claude Code](https://claude.com/claude-code). Коммиты агента
помечены трейлером `Co-Authored-By: Claude`.

## Роли

**Разработчик** ставит задачу и принимает решения: стек (React + Redux Toolkit / RTK Query),
состав функций, приоритеты и сроки, способ деплоя (GitHub Pages), формат документации.
Проверяет результат и отвечает за него.

**Агент** разбивает задачу на этапы, пишет код, тесты, коммиты и документацию, прогоняет
проверки после каждого шага.

## Цикл работы

1. План: разбиение на этапы, каждый из которых заканчивается рабочим состоянием и коммитом.
2. Шаг: реализация этапа → `lint`, `tsc`, `build` (позже и `test`) → коммит.
3. Итерации видны в истории: сначала простое рабочее решение, затем улучшение. Например, API:
   `fetch` → RTK Query; получение сообщений: `setInterval` → удаление уведомлений →
   последовательный long polling с остановкой и дедупликацией.

**Сроки.** Каркас (шаблон, линтеры) сделан 26.09. Основная разработка заняла один вечер 29.09,
около 4 часов: 16 коммитов с 18:24 до 22:05. Последние этапы объединены в более крупные коммиты,
чтобы уложиться в это время. Работа с агентом позволила пройти за вечер путь, рассчитанный на
несколько дней, не пропуская проверки на каждом шаге.

## Контроль за агентом

Результат агента проверяется так же, как код коллеги: тесты, линтер, CI. После основной
разработки проведено отдельное ревью: свежий агент без контекста проверял репозиторий по
заданию. Что нашли и исправили:

- CI упал на `Array.prototype.at`: локально ошибку скрывал кэш `tsc -b`. Подняли `target` до
  ES2022, проверки теперь гоняются и на чистом кэше.
- Исключение при разборе уведомления могло остановить цикл до `deleteNotification`, а сбой
  удаления вызывал повторные запросы без паузы. Добавлены `try/catch` и пауза при ошибке.
- Состояние писалось в `localStorage` на каждый экшен, включая служебные экшены опроса.
  Теперь запись идёт только при изменении `auth` или `chats`.
- Неточные ссылки на строки кода в [REVIEW.md](REVIEW.md) исправлены.
